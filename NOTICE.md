# Catatan asal kode dan aset

Ekspor ini berasal dari source lokal yang dipisahkan dari folder koleksi kerja. Berkas environment aktual, kredensial, database pengguna, dependency yang terpasang, serta riwayat Git lokal tidak disertakan. Dokumen ini tidak memberikan lisensi baru atas aset atau kode pihak lain.

Gambar dan nama game mengikuti source awal dan tetap menjadi milik pemilik mereknya. Tidak ada lisensi proyek terpisah yang ditemukan.
